# 📝 To-Do List — Gerenciador de Tarefas

Aplicação web desenvolvida com **HTML, CSS e JavaScript**, com o objetivo de praticar manipulação do DOM, eventos e operações de CRUD.

O projeto permite gerenciar tarefas de maneira simples e intuitiva, mantendo os dados salvos no navegador por meio do `localStorage`.

## 🚀 Funcionalidades

- ✅ Adicionar novas tarefas
- 📋 Visualizar tarefas cadastradas
- ✏️ Editar a descrição de tarefas
- ✔️ Marcar tarefas como concluídas ou pendentes
- 🗑️ Excluir tarefas com confirmação
- 🔢 Visualizar a quantidade de tarefas pendentes
- 💾 Salvar tarefas automaticamente com `localStorage`
- 📱 Interface responsiva para diferentes tamanhos de tela

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura da aplicação
- **CSS3:** estilização e responsividade
- **JavaScript:** lógica, eventos e manipulação do DOM
- **localStorage:** persistência dos dados no navegador

## 📚 Conceitos praticados

- Manipulação do DOM
- Eventos com `addEventListener()`
- Arrays e objetos
- Funções e condicionais
- Métodos `push()`, `find()`, `filter()`, `map()` e `forEach()`
- Criação dinâmica de elementos HTML
- Operações CRUD (Create, Read, Update, Delete)
- Conversão de dados com `JSON.stringify()` e `JSON.parse()`
- Armazenamento local com `localStorage`

## ▶️ Como executar

1. Clone o repositório ou baixe os arquivos.
2. Abra a pasta do projeto no VS Code.
3. Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server.
4. Adicione e gerencie suas tarefas.

Não é necessário instalar dependências.
